# 🧠 Decision Lab — Backend API

API REST para registrar, analizar y visualizar decisiones personales.  
Parte del ecosistema **Decision Lab**.

---

## 🚀 Stack

- **Runtime:** Node.js + Express
- **Base de datos:** PostgreSQL + Knex.js (migraciones y seeds)
- **Autenticación:** JWT + bcrypt
- **Validación:** Zod
- **Documentación:** Swagger
- **Testing:** Jest + Supertest

---

## ✅ Requisitos

- Node.js 18+
- PostgreSQL 14+
- Git
